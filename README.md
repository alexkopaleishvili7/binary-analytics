# Binary Analytics

A website demo for a future company concept called **Binary Analytics** - a company that helps startups and businesses grow, whether through technical solutions or financial insight.

This is a solo learning project. I'm using it to build essential front-end and back-end development skills from the ground up. The site is a work in progress and will continue to evolve over time.

Suggestions are welcome, feel free to fork the repo and open a pull request if you'd like to contribute.

## Live Demo

[alexkopaleishvili7.github.io/binary-analytics](https://alexkopaleishvili7.github.io/binary-analytics/)

## Features

- Light/dark theme switching with persistent preference
- Fully responsive layout (mobile, tablet, desktop)
- Accessible UI (ARIA labels, keyboard navigation, focus states)

## Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla)
